🔒 Security Layer — Hacker-Resistant

  • End-to-end encryption: Every message is encrypted with AES-GCM 256 using a key derived via ECDH P-256. Only you and your peer can read it.
  • Anti-replay: Each message carries a unique nonce + timestamp; replays are rejected.
  • Anti-tamper: HMAC-SHA256 over ciphertext detects any modification in transit.
  • Anti-XSS: All user content is tokenized and HTML-escaped before render — no innerHTML with raw input.
  • CSP-locked: Content-Security-Policy blocks inline event handlers and untrusted sources.
  • Key fingerprint: Verify your peer's identity by comparing the E2E fingerprint shown in chat header.
